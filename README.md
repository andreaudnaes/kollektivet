# Kollektiv app

En app som gjør samarbeidet i et kollektiv enklere og mer oversiktlig.

## Hva appen inneholder
- Handleliste
- Kalender
- Vaskeliste
- Beholdning

## Mål
- Mindre misforståelser
- Enklere planlegging
- Bedre oversikt over fellesoppgaver

## Tech stack (planlagt)
- Runtime: Bun
- Backend: Elysia
- Database: PostgreSQL
- ORM: Drizzle
- Frontend: React + Vite
- Styling: Tailwind (eller CSS Modules)
- Auth: Lucia (valgfritt)
- Testing: Bun test
